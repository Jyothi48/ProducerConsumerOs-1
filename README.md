Producer-Consumer Problem in Java
#Description

This project implements the Producer-Consumer problem using threads in Java.
The producer produces items and adds them to a shared buffer, while the consumer removes and consumes the items from the buffer.

#Concepts Used
Java Threads
Thread
synchronized
wait()
notifyAll()
Shared Buffer
Producer-Consumer Problem

#Files
SharedBuffer.java – Manages the shared buffer and synchronization.
Producer.java – Produces items.
Consumer.java – Consumes items.
ProducerConsumer.java – Main class used to create and start the threads.

#How to Run
Compile the Java files and run the ProducerConsumer class.

#Output
The program displays the items produced by the producer and consumed by the consumer.

#Result
The Producer-Consumer problem was successfully implemented using threads in Java.
